# 荒原余烬

一个无需联网、无需安装依赖的 Canvas 无尽生存小游戏。玩法受到幸存者类动作游戏启发，代码、美术和音效均为原创的程序化实现。

原作机制拆解和本地版数值映射见 `DESIGN_NOTES.md`。

## 运行

直接双击 `index.html`，或在目录中启动任意静态文件服务器：

```bash
python3 -m http.server 4173
```

浏览器访问 `http://localhost:4173`。

## 性能诊断

使用 `http://localhost:4173/?perf=1` 启用低频性能采样。浏览器控制台可调用：

```js
window.__emberPerf.snapshot()     // 最近 120 个运行帧的阶段耗时与对象数量
window.__emberPerf.fillEnemies(180) // 填充敌人，用于稳定压力测试
```

自动化测试可直接打开 `?perf=1&stress=180`，开始游戏后会填充对应数量的敌人，并把最新报告写入隐藏的 `#perf-output` 元素。升级购买流程可使用 `&coins=100&collect` 提供测试金币并自动吸取掉落。

武器表现回归可使用 `&loadout=bow:6,bomb:6,chopper:6&god` 指定测试武器并开启测试无敌状态。

普通游戏地址不会启用采样逻辑。

## 操作

- `WASD` / 方向键：移动
- `Esc`：暂停/继续
- `1` / `2` / `3`：选择升级
- 触屏设备：使用左下角虚拟摇杆

游戏会自动攻击最近的敌人，拾取紫色余烬可获得经验，升级后从三个随机强化中选择一个。

## 游戏内容

- 3 名英雄，拥有不同初始武器、生命、速度、护甲和被动特性
- 12 种主动能力：9 种通用武器，以及术士专属的持续雷击、火球术和寒霜新星；术士以雷击开局，另外两种法术通过升级学习
- 9 种被动强化：冷却、护甲、金币、磁铁、移速、经验、武器伤害、法术伤害和范围伤害半径
- 每名角色在 10、20、30 级各进行一次职业天赋二选一，天赋不占武器槽位
- 12 种武器进化：武器达到 6 级并持有对应被动后，会在升级池出现最终形态
- 灼烧、感电和冻结拥有独立状态；非冰伤害可触发碎冰，灼烧与感电会触发超载
- 当常规强化全部达到上限后，升级池会转为可重复的无尽威能、无尽生机和无尽律动
- 场景中的瓶子和宝箱会掉落生命、金币与经验
- 敌人生命、速度、数量与刷新频率会随时间持续增长
- 难度曲线在前 7 分钟平滑加速，后期通过生命和伤害继续增长，避免刷新数量突然翻倍
- 荒原守望者会周期性出现，击败后游戏继续，不存在最终波次
- 死亡时将本局金币带回，可用于解锁和强化英雄
- 升级选择支持金币重抽、额外强化、放逐卡牌和跳过整备；击败 Boss 会奖励一次免费重抽，并有严格的已拥有强化保底
- 标题界面的远征补给商店提供生命、伤害和免费重抽三类永久升级，旧存档会自动补齐这些字段
- 死亡结算时可使用远征金币复活一次：费用随生存时间和等级提高，复活恢复 45% 生命并获得 3 秒无敌；再次死亡不会重复结算已带回的金币
